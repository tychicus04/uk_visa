## 📈 KPIs TO TRACK

### App Store Optimization (ASO)
1. **Keyword Rankings** - Track position for main keywords
2. **Impression-to-Install Rate** - Target: 5-10%
3. **Screenshots View Rate** - How many view beyond first
4. **Search vs Browse installs** - Optimize accordingly

### User Engagement
1. **Day 1 Retention** - Target: 40%+
2. **Day 7 Retention** - Target: 20%+
3. **Day 30 Retention** - Target: 10%+
4. **Average Session Duration** - Target: 10+ minutes
5. **Tests Completed** - Per user metric

1. **Crash-Free Rate** - Target: 99.5%+
2. **Average Rating** - Target: 4.5+ stars
3. **Review Sentiment** - Track positive/negative ratio
4. **Bug Reports** - Trend should decrease over time
